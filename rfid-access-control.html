Smart RFID Access Control & Cloud Attendance.

An embedded access-control concept that combines RFID credential reading, physical access control, and cloud-based attendance records.

01 / OVERVIEW

Access made traceable.

The system uses an ESP32 microcontroller and an MFRC522 RFID reader connected over SPI to read access credentials. When a credential is validated, the ESP32 can control a relay module for a physical locking mechanism and send entry timestamps to a Firebase database over Wi-Fi.

The intended workflow brings together local hardware interaction and remote attendance logging. Detailed wiring, firmware, screenshots, test results, and implementation notes can be added as the project documentation is uploaded.
